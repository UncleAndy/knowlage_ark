# KOVCHEG (Ковчег знаний)

Загрузочный носитель для постапокалипсиса: флешка, которая грузится почти на любом
железе, сама является системой и даёт читать библиотеку документов (PDF внутри ZIP) без
установки, без сети и без рабочей ОС на машине. Загрузочный слой — на базе Ventoy,
читалка — своя, минимальная, поверх framebuffer. Собирается из исходников одним флейком.

## Состояние

Стадия — M0a «инструментарий» (плана реализации, код читалки ещё не начат).
На этот момент сделано: закреплённый flake, матрица пяти целевых архитектур,
пробы сборки компонентов под каждую цель и последовательный раннер с отчётом.

## Что уже решено (кратко)

- Архитектуры v1: x86_64 (BIOS и UEFI x64), i686 (старый BIOS и 32-битный UEFI), aarch64
  (UEFI). armv7 и riscv64 — best-effort, только через раздел ARKBOOT и U-Boot distro-boot.
- Носитель: одна флешка (риск потери носителя принят осознанно).
- Сборка: вариант B — всё из исходников; единственное объявленное исключение — сам Ventoy.
- Контент в проект не входит: проект поставляет формат, инструменты, читалку и проверку целостности.

## Команды

```bash
nix flake check                 # матрица целей и полнота проб
nix develop                     # python, jq, xorriso, mtools, file, binutils
nix build .#probe-aarch64-kernel          # ядро под цель с нашим фрагментом конфига
nix build .#probe-armv7-mupdf-fallback    # компонент, пересобранный запасным набором
bash probe/run-m0a.sh pass1 [--rebuild]   # замер по x86_64 и aarch64
bash probe/run-m0a.sh pass2 [--rebuild]   # замер по i686, armv7, riscv64
```

Отчёт раннера пишется в `docs/reports/<дата>-m0a-toolchain-<pass>.tsv`. В каждой строке
указано, какой набор nixpkgs её собрал и её провенанс: `cache` (готовый артефакт из
бинарного кэша), `local` (скомпилировано здесь), `rebuilt` (скомпилировано здесь
принудительно, с `--rebuild`). Время сборки имеет смысл только у строк `local` и `rebuilt`.

## Структура

```
flake.nix                      закреплённый nixpkgs, плоские выходы probe-<цель>-<компонент>
nix/targets.nix                матрица целей: наборы, слой прошивки, строка ELF-машины
nix/probe.nix                  компоненты на цель: selftest, busybox, kernel, mupdf
nix/selftest.nix               сборка статической пробы с проверкой через readelf
probe/selftest.c               сама проба: печатает архитектуру, разрядность, порядок байт, libc
probe/run-m0a.sh               последовательный раннер замеров с вердиктами
docs/superpowers/plans/        планы этапов
docs/reports/                  замеры (tsv) со временем, размерами и провенансом
drafts/                        обсуждения и нормативно не связывающие документы
```

## Правила проекта

- Пороги и критерии фиксируются до прогонов; опровержение результата — тоже результат.
- Наличие атрибута в nixpkgs не считается доказательством сборки: PASS ставится только
  по собранному артефакту, а для кросс-целей — по readelf (строка машины и отсутствие
  `PT_INTERP`), потому что запустить кросс-бинарник на машине сборки нельзя.
- Никаких готовых сторонних бинарников, кроме Ventoy.
